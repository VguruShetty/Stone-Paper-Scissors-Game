# 🪨📄✂️ Stone, Paper & Scissors Game

A fun, interactive Stone–Paper–Scissors web game built using HTML, CSS, and JavaScript.
Play against the computer, track your score, and enjoy clean visuals with dynamic messages for wins, losses, and draws.

🚀 Live Demo

👉 Play the Game Here

🧩 Features

🎮 Simple and interactive gameplay

🧠 Random computer moves each round

🏆 Real-time score tracking

🟢 Winning and 🔴 losing message display

🧱 Responsive design with smooth hover effects

🛠️ Technologies Used

HTML5 – structure of the game

CSS3 – design and styling

JavaScript (ES6) – game logic and score management

⚙️ How to Run the Project Locally

Clone the repository:

git clone https://github.com/VguruShetty/Stone-Paper-Scissors-Game


Open the folder in VS Code or any editor.

Run the project by opening index.html in your browser.

🧠 Game Rules

Choose Stone, Paper, or Scissors.

The computer randomly selects one option.

Rules:

🪨 Stone beats Scissors

📄 Paper beats Stone

✂️ Scissors beat Paper

If both choices are the same → it’s a Draw.
